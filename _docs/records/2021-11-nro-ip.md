NRO RADIUS 서버가 있던 대역의 게이트웨이를 옮기면서 서비스가 잠시 끊겼고, 이어서 서버 IP 대역이 바뀌었습니다. 참여기관은 자기 방화벽과 RADIUS 서버 설정을 함께 고쳐야 했습니다.

## 작업 내용

| 일자 | 작업 | 영향 |
|---|---|---|
| 2021-11-27 (토) 13:00–18:00 | eduroam 서버 IP 대역 게이트웨이 이전 | 작업 시간 안에서 30분가량 서비스 단절 |
| 2021-12-03 (금) 22:00 – 12-04 (토) 02:00 | eduroam 서버 IP 대역 변경 (4개 주소) | 참여기관의 인증 서버 IP 설정과 보안장비 설정 변경 필요 |

## 공지 원문

2021년 11월 26일 KISTI 연구망센터가 전남대·고려대·NIMS·지질연·표준연·DGIST·포항공대·KAIST 에 보낸 공지입니다. 사람 이름과 실제 주소는 가립니다.

```text
Subject: [중요][KISTI][에듀롬] 서비스 단절 및 국가 에듀롬 서버 IP 변경 공지

국가 에듀롬 서버에 중대한 단절 및 변경사항이 있어 공지 드립니다.

11.27 작업은 30분 정도 서비스가 단절됩니다.

12/3~4에 예정된 작업은 IP가 변경하는 작업입니다.
원내에 구비하신 방화벽과 에듀롬 서버에서 바뀐 IP를 적용해 주셔야 합니다.

1. 서비스 단절 공지
 - eduroam Server IP 대역 Gateway 이전 작업으로 인한 서비스 단절
  → 대상 IP : 198.51.100.51 ~ 54 (4개)
 - 작업시간 : 2021.11.27(토) 13:00 ~ 18:00 (작업시간 내 30분 서비스 단절 예상)

2. eduroam Server IP 대역 변경 작업 공지
 - 기존 IP : 198.51.100.51 ~ 54 → 변경 IP : 203.0.113.51 ~ 54
 - 작업시간 : 2021.12.03(금) 22:00 ~ 12.04(토) 02:00 (4시간)
 - eduroam 서비스 사용 기관 내 인증 Server IP 변경 및 보안장비 설정 변경 필요
```

> [!NOTE]
> 위 주소는 [RFC 5737](https://www.rfc-editor.org/rfc/rfc5737) 의 문서용 대역으로 바꿔 적은 것입니다. 실제 주소가 아닙니다.

## 남은 것

참여기관 전체에 영향을 주는 변경을 메일 한 통으로만 알린 일입니다. 지금은 [공식 웹사이트](https://eduroam.kreonet.net/notices/)에 공지를 남기고, 서버 정보는 [운영약관]({{ '/rules/provisions/' | relative_url }})이 정한 경로로 알립니다.
