## eduroam 개요

소속기관의 아이디와 비밀번호로 로그인하면 eduroam 참여기관의 Wi-Fi 를 쓸 수 있고, 한 번 설정하면 추가 설정 없이 전 세계에서 쓸 수 있다고 설명했습니다.

보안 측면에서는 Wi-Fi 로그인 때 소속기관 서버와 암호화된 연결로 인증하므로, 소속이 불분명한 Wi-Fi 에 붙어 생기는 피싱·파밍 사고를 예방한다고 적었습니다. 유럽은 공공 인프라로서 공항·박물관·관광지에서도 운영한다는 점을 덧붙였습니다.

## eduroam 연혁 (2017년 기준)

**2003년** TERENA 의 TF-MNM 에서 eduroam 을 제안하고 구축했습니다.

- TERENA 는 GÉANT 의 전신으로 1986년부터 유럽 연구교육망을 운영하고 연구해 왔습니다
- MNM-TF 는 Mobility and Network Middleware Task Force 로, 최신 네트워크 이동성·로밍 기술을 국가연구교육망(NREN)에 적용하고 시험하는 것이 목적이었습니다
- 2000년 당시 최신 원격 인증 기술이던 RADIUS(RFC 2138)를 적용해 Wi-Fi 로밍 서비스를 제안하고 구축했습니다

**2016년** 유럽의회가 디지털 단일시장(DSM) 우수사례로 소개했습니다. 같은 해 누적 인증 10억 건을 달성했고, 국제 사용량 23%, EU 내 사용량 26% 증가를 기록했습니다.

**2017년** 89개국 2만여 기관에서 쓰고 있었습니다.

## 아시아태평양 주요국 현황 (2017년 기준)

**호주** 2004년 연구교육망 AARNet 연결로 시작해, 2017년 73개 대학·연구소·병원·관공서·관광지가 참여했습니다. AARNet 이 운영하고, 2016년 기준 월 평균 20만 명이 이용했으며 해외 이용자 비중이 8% 까지 올라왔습니다.

**홍콩** 2006년 홍콩 폴리테크닉 대학 연결로 시작해 2017년 15개 대학·연구소가 참여했습니다. 홍콩 대학연합 컴퓨터센터(JUCC)가 운영하며, JUCC 는 연구교육망 HARNET 도 운영합니다.

**일본** 2006년 도호쿠 대학의 참여로 시작해 2017년 178개 대학·연구소가 참여했습니다. 연구교육망 SINET 을 운영하는 국립정보학연구소(NII)와 겸직 중인 도호쿠 대학 인력이 운영했습니다.

**미국** 2009년 테네시 대학교와 NSF 의 연결로 시작해, 2012년 Internet2 의 기본 서비스가 되며 220여 대학이, 2017년에는 524개 대학·연구소가 참여했습니다.

## eduroam 과 일반 공공 Wi-Fi 의 차이

**eduroam 이 안전한 이유**

- 이용자마다 다른 정보로 인증하고 암호화해 전송합니다 (WPA-EAP)
- 이용자마다 다른 아이디와 비밀번호를 씁니다
- 가짜 AP 를 가려낼 서버 인증서를, eduroam 을 쓰기 전에 신뢰할 수 있는 경로로 미리 설치하도록 권장합니다
- 소속기관을 통해 신원이 확인된 이용자만 쓰므로 운영 측면에서도 안전합니다

**일반 Wi-Fi 의 문제**

- 암호 없이 누구나 붙는 Wi-Fi 는 해킹 위험에 노출됩니다. 금융거래나 개인정보 취급은 매우 위험합니다
- 암호가 있어도 하나의 암호를 여럿이 공유하면 마찬가지입니다. 카페나 식당의 Wi-Fi 비밀번호 공유가 그렇습니다
- 당시 `wififree.kr` 의 공공 Wi-Fi(Public Wifi Secure)도 모든 이용자가 같은 인증정보를 쓰고(아이디 `wifi`, 비밀번호 `wifi`) 서버 인증서 설치 절차가 없어 같은 위험이 있었습니다
- 본인이 가입한 통신사 Wi-Fi 는 USIM 정보로 이용자마다 다른 키를 써서(WPA-EAP-SIM) 대부분 안전하지만, 가입한 통신사에 종속됩니다
